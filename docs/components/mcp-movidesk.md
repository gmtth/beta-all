# MCP Movidesk

O código ativo do servidor MCP, OAuth, APIs e runtime do Site fica em `mcp/movidesk/`. Leia [`AGENTS.md`](../../mcp/movidesk/AGENTS.md) e [`DOSSIER.md`](../../mcp/movidesk/DOSSIER.md) antes de mudanças no componente.

O estado local não enviado em 2026-10-20 não foi aplicado ao runtime. O branch e os arquivos pendentes estão preservados em `legacy/source-archives/mcp-local-branch/` e `legacy/local-snapshots/mcp-2026-10-20/`. As versões locais de AGENTS/DOSSIER e documentos correlatos também estão em `docs/migration/source-documents/mcp-local/` para comparação.

Para trabalhar nesse componente, use a raiz do monorepo para operações Git e `mcp/movidesk/` como diretório de execução dos comandos documentados no AGENTS/README do MCP. Não publique no Sites por efeito implícito de uma edição local.
