# Preservação local do source-bundle

Esta pasta contém os arquivos recuperáveis de `MCP Movidesk/work/legacy-preservation/`, sem `node_modules`. Inclui compilações `dist/` e estágios locais de empacotamento v11/v12. O código-fonte e o histórico do branch MCP local também estão preservados em `legacy/source-archives/mcp-local-branch/source-bundle/`.

Não usar os artefatos `dist/` como fonte de desenvolvimento. `SHA256SUMS.txt` permite conferir a cópia. O diretório original permanece intacto.
