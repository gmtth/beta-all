# Arquivos locais legados

`artefatos-publicacao-20261019.zip` guarda, com os caminhos relativos preservados:

- a pasta `_site-package-stage/` e seus pacotes de estágio;
- a pasta `dist/` gerada localmente;
- os 35 arquivos `.tar.gz` que estavam na raiz.

São cópias locais de publicação e recuperação, não código ativo do Site. Extraia o ZIP na raiz do projeto para restaurar os caminhos originais. O ZIP é ignorado pelo Git para não enviar artefatos de publicação ao repositório.

O backup recuperável do código e dos arquivos locais do antigo `source-bundle` permanece separado em `work/legacy-preservation/`.
