# Prioridade e comparação de fontes

## Ordem de autoridade

Aplicar:

1. decisão explícita confirmada mais recente;
2. arquivo declarado pelo usuário como fonte atual;
3. regra oficial mais recente aplicável;
4. card ou comentário oficial mais recente;
5. Figma aprovado;
6. documentos anteriores;
7. contexto histórico.

A prioridade resolve autoridade, mas não apaga automaticamente uma divergência que ainda precise ser registrada.

## Recência funcional

Avaliar a vigência pelo conteúdo, verificando:

- nomenclatura;
- regras substituídas;
- decisões posteriores;
- status;
- comentários;
- aprovação;
- contexto;
- indicação de produção, validação, proposta ou futuro.

Não usar somente data de modificação.

## Matriz de comparação

| Classificação | Critério | Tratamento |
|---|---|---|
| Compatível | Mesmo significado funcional | Consolidar sem criar divergência |
| Complementar | Uma fonte detalha sem contradizer | Preservar o detalhamento compatível |
| Divergência funcional | Resultados, gatilhos, dados, permissões, mensagens ou processamento incompatíveis | Não escolher silenciosamente; devolver à Beta |
| Regra ausente | Uma fonte não define ponto material | Não preencher por inferência |
| Substituída | Há decisão posterior confirmada | Manter apenas como histórico de rastreabilidade |
| Evidência desatualizada | A fonte descreve estado anterior ou imagem antiga | Não usar como vigente |
| Futuro | Proposta/entrega ainda não vigente | Separar do comportamento atual |
| Não confirmado | Falta autoridade suficiente | Devolver como ponto a decidir |

## Diferenças que não são conflito

Não tratar como divergência quando houver apenas:

- redação diferente com mesmo significado;
- maior ou menor detalhamento compatível;
- exemplos distintos que não alterem a regra;
- formatação diferente;
- nomenclatura antiga sem efeito funcional quando a equivalência estiver explícita.

## Recomendação de consolidação

A recomendação deverá indicar:

- qual fonte deve sustentar o entendimento vigente;
- quais fontes apenas complementam;
- quais pontos devem ser preservados como histórico;
- quais divergências precisam de decisão;
- quais itens pertencem ao futuro.

Não formular uma nova regra para resolver falta de evidência.
